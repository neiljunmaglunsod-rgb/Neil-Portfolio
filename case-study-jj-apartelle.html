AI Comment-to-Booking Automation

J&J Apartelle — Surigao City, Philippines

An always-on workflow that reads Facebook comments in Bisaya and Taglish, understands what each person actually wants, and responds the right way — turning a public comment into a private booking conversation without a manual first reply.

The problem

Comments were coming in — replies weren't going out

J&J Apartelle receives booking interest as comments on Facebook posts. Answering them by hand was slow, and the page's auto-reply sent the same generic "message us on Messenger" response to everyone — including past guests who were leaving glowing reviews.

The result: booking questions could wait for a reply, and guests praising their stay got a sales message back.

The solution

An automation that reads intent, then acts

I built a workflow that runs when someone comments, reads the comment in the guest's own language and routes it down the right path.

1

Comment detected

A new comment on a page post reaches the workflow through a Facebook webhook. Comments from the page itself are filtered out.

2

AI reads the intent

An OpenAI classifier reads the comment in Bisaya, Cebuano, or Taglish and decides what the person actually wants.

3

Routed to the right response

Based on intent, the comment is sent down one of three paths — booking, review, or everything else.

Booking question

Public reply + private DM

Sends a private Messenger message and posts a public reply. The message opens the conversation with the AI booking assistant, which asks for guests and dates.

Review / thank-you

Warm, personalized reply

Writes a thank-you that mentions what the guest praised, with no sales pitch and no private message.

Everything else

Left alone

Tagged friends, lone emojis and off-topic comments get no automated reply.

Engineering details

Built with safeguards

Mixed-language comments

The classifier handles mixed Bisaya, Cebuano and Taglish, where keyword rules fall short because words like "salamat" appear in both thank-yous and enquiries.

Safe fallback

If the AI returns something unexpected, the parser falls back to the booking path instead of stopping, so an unclear result is treated as a possible lead.

Response parsing

A dedicated code step reads the model's JSON output and validates the category before routing, so a malformed response cannot send a comment down the wrong path silently.

Non-intrusive integration

The comment handler runs as a separate sub-workflow called by the Messenger booking bot, which keeps comment logic apart from booking logic.

Workflow architecture

How the booking setup fits together

1

Facebook webhook

Comments and Messenger messages arrive at the n8n booking bot.

2

Comment sub-workflow

Filter new comments → classify with OpenAI → parse the result → route to review, other or booking.

3

Messenger booking agent

Collects guest details, checks availability in Google Calendar, blocks dates, sends confirmation and GCash payment details, and alerts the owner on Telegram. It offers another unit if the first choice is taken.

4

Supporting workflows

Airbnb iCal sync every 15 minutes for all 4 units, release of unpaid holds, and error notifications.

Results such as response time or bookings gained aren't published here because they haven't been measured yet.
