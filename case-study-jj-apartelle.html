The problem

Comments were coming in — replies weren't going out

J&J Apartelle gets most of its booking interest as comments on Facebook posts. But answering them was manual and slow, and the page's auto-reply sent the same generic "message us on Messenger" response to everyone — including past guests who were leaving glowing reviews.

The result: potential bookings sat unanswered for hours, and happy guests praising their stay got a cold sales message back, making the page look like it wasn't even reading its own comments.

The solution

An automation that reads intent, then acts

I built an end-to-end workflow that fires the moment anyone comments, understands the comment in the guest's own language, and routes it down the right path — all automatically.

1

Comment detected

A new comment on any page post triggers the workflow instantly through the Facebook Graph API and webhooks.

2

AI reads the intent

An OpenAI classifier reads the comment in Bisaya, Cebuano, or Taglish and decides what the person actually wants.

3

Routed to the right response

Based on intent, the comment is sent down one of three paths — booking, review, or everything else.

Booking question

Public reply + private DM

Posts a public reply, then slides into the person's Messenger with a booking message that hands off to an AI booking assistant for dates, availability, and rates.

Review / thank-you

Warm, personalized reply

Writes a genuine thank-you that references what the guest praised — no sales pitch, no DM. Past guests feel seen.

Everything else

Left alone

Tagged friends, lone emojis, and off-topic comments are correctly ignored instead of getting a robotic reply.

Engineering details

Built to run unattended

Bilingual understanding

The classifier reads mixed Bisaya, Cebuano, and Taglish reliably — where simple keyword rules would fail, because words like "salamat" appear in both thank-yous and inquiries.

Fail-safe by design

If the AI ever returns something unexpected, the workflow falls back to the booking funnel instead of going silent or erroring — so a lead is never dropped.

Tested before going live

Every path was verified end-to-end against real comment data before deployment, catching a response-parsing bug that would have misrouted reviews.

Non-intrusive integration

The comment handler branches off the existing Messenger booking bot without touching or slowing down live payment and booking traffic.
