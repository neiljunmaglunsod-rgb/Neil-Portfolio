Business problem

Philippine payroll has many rules to get right

A manpower agency must apply regional wage orders, holiday and overtime premiums, and SSS, PhilHealth and Pag-IBIG contributions for each pay period. Doing that by hand makes errors more likely and is hard to check.

Automation solution

A tested calculation engine and PDF payslips

The app keeps wage rates and contribution tables as reference data, computes each payslip with pure, tested functions and generates a PDF. Attendance, full payroll runs and client billing are planned as later phases.

Workflow architecture

How it works

1

Reference data

Wage rates and contribution brackets are stored in the database and looked up by date.

2

Payslip form

The user enters worker details and attendance. The server validates the input again and never trusts values from the browser.

3

Payroll engine

Computes basic pay, overtime, night differential, rest day and holiday premiums, then statutory and other deductions.

4

PDF output

A react-pdf template renders the payslip for download.

Build details

Automated tests

As of September 2026, the project had 194 passing tests, including 23 for the payroll engine.

Money in centavos

Amounts are calculated as integer centavos to avoid rounding errors from decimal arithmetic.

Server-side checks

Payslip requests require a signed-in user and are validated with Zod.

Honest limits

Employee records, payroll-run saving and withholding tax tables were still pending at that point.
